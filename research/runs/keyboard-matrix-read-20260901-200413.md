## Interpretation boundary

- The controller stores 128 four-byte slots; the signed software maps these slots to the model-specific keyboard layout.
- A default-matrix match proves factory assignments are present, not that every shared macro feature is enabled in the UI.
- Macro records were not requested by this diagnostic.

## Local comparison with Gigabyte's signed `3a4041` default

- Byte differences: `5 / 512`.
- Differing records: `5 / 128`.
- All five corresponding signed-default records are zero; the live controller contains:
  - slot 79: `00 00 88 00`
  - slot 80: `00 00 87 00`
  - slot 88: `00 00 89 00`
  - slot 93: `00 00 89 00`
  - slot 117: `00 00 8B 00`
- Gigabyte marks user-created macro/basic-hotkey assignments with record type `3`, `4`, or `10` in byte 0. The live matrix contains **zero** records with those markers.
- Therefore the five differences are secondary/special-key codes outside the generic signed template, not evidence of a saved user macro or remapped normal key. Their exact physical-key meaning is not labeled by the firmware response and is left uninterpreted.
