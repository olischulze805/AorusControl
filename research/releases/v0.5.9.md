# AORUS Control 0.5.9

## A clearer, safer updater

The update card now distinguishes checking, downloading and installing instead of calling a
download an installation. It shows the installed and available versions, provides a real
download progress bar, links to the matching release notes and uses the unambiguous final
action **Restart and install** / **Neu starten und installieren**.

Update state is represented explicitly rather than being stored as a collection of unrelated
status strings. This also means status and version text switch language immediately, including
runtime progress and errors.

## Automated releases

Every push and pull request now runs a Windows CI workflow with the release build, the complete
logic suite and the offscreen UI checks. Pushing a semantic version tag additionally validates
the tag against the project and release-notes versions, restores the preceding package for
delta generation, builds the self-contained installer and update feed, writes SHA-256 checksums
and publishes the GitHub release. A failed check cannot create a partial release.

The local release script follows the same gates and refuses mismatched versions or missing
artifacts. Its UI verification mode no longer rewrites tracked README screenshots.

## Unattended tests

The smoke and UI executables disable native Windows crash pop-ups. Failures still retain their
stack trace and non-zero exit code, but can no longer block a terminal or CI runner behind a
modal “unknown software exception” dialog.
