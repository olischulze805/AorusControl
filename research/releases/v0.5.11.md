# AORUS Control 0.5.11

## Graphics rules now follow the power source reliably

Per-program GPU rules are now applied automatically after Windows starts and whenever the
laptop changes between mains and battery power. Opening the Graphics page or pressing **Apply
now** is no longer required.

Windows power notifications remain the fast path. A lightweight fallback also reads the
Windows power status every two seconds, recovering when an event is missed or the source is
briefly unknown during an early tray start. It only acts when the known source changes, never
writes for an unknown source and does not query or wake the NVIDIA GPU.

The log now records which source was applied, how many managed programs changed and whether a
write failed, making startup behaviour diagnosable without opening the app.

## Verified

Release build without warnings, the complete smoke-test suite and the offscreen UI checks at
all supported widths pass. A dedicated regression test covers an initially unknown source,
recovery to mains and a subsequent battery switch without opening the Graphics page.

The actual Windows preference still takes effect the next time the affected program starts;
Windows cannot move an already running program between GPUs.
