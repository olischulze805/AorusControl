# AORUS Control 0.5.8

## Complete, natural German and English

The language selected under **About & updates** is now applied before any feature creates its
first status line. This fixes mixed windows such as English controls with “Aktiv:
Ausbalanciert (Netzbetrieb)” underneath.

The translation pass now covers 351 strings, including runtime status, errors, program search,
update progress, keyboard effects and fan-curve messages. Wording was reviewed in context too:
literal phrases such as a “CPU cap” are now called **processor limit** / **Prozessorlimit**, and
awkward translations around startup, power adapters and inactive curves were rewritten.

Keyboard effect names are generated from the active language instead of being captured once
at construction, so switching language also updates that list.

## Battery saver restart safety

The saver now remembers both its copied power plan and the user's original plan. After a normal
app restart it adopts the still-active copy instead of copying an already limited plan again.
Turning the saver off can therefore always return to the correct original plan, and repeated
restarts no longer accumulate nested copies.

The switch and sliders are disabled during a plan change. A rapid second toggle can no longer
be accepted visually and then dropped while the first operation is still running.

## Download numbers

The README explains why it does not display GitHub's release-asset counter as a people or
installation count: it includes repeat asset requests and automatic updater traffic. GitHub
does not provide a public unique-human download metric, so presenting that number as people
would be misleading.
