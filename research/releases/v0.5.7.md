# AORUS Control 0.5.7

## English

The whole interface speaks English now, switchable under **About & updates** without a
restart — 298 strings, including the sentences the app builds around numbers, not just its
labels. It follows Windows by default. Numbers follow the language too, so an English window
no longer prints a decimal comma.

Both vocabularies are compared key by key by a test, so a forgotten translation fails the
build rather than turning up in a window months later.

## Battery saver

New card under **Power & battery**. It caps the display brightness and the maximum processor
state on battery, and says what each is worth on this machine: the screen at 30 % saves about
3 W, measured here — the processor cap saves nothing at idle and only bites under load.

Gigabyte's own version wrote those two values into your Balanced power plan and kept the old
ones in the registry, so a crash between setting and restoring left the machine capped with
nothing left that knew why. This one copies your plan, changes the copy, and switches to it.
Your own plans are never written to; turning it off goes back and deletes the copy. If the app
is ever killed while it is on, the next start cleans the copy up.

Only the battery side is written, so on mains the machine behaves exactly as before — there is
no automatic to set up and the switch can simply stay on.

Worth knowing: the largest saving on this laptop is not on this card. It is the discrete
graphics card, one tab over.

## A new icon

A three-bladed fan instead of the black square with a gauge. The square dissolved into a dark
taskbar, so the icon had no silhouette of its own, and the gauge was already the Dashboard
entry's symbol. Nine sizes, all drawn from one geometry by `tools/Build-AppIcon.ps1`.

## Graphics is its own tab

It used to share the power page. With a running-programs list, a close button and two rules
per program it had become its own subject, and the power page is back to breathing room.

## Smaller things

- The power-mode card's explanation moved behind its info dot. It had been a panel taking a
  third of the page, including a second copy of the fan curve that can only be edited on the
  cooling page anyway.
- Each graphics rule row needed three lines of height for two drop-downs; the labels sit
  beside them now, so it is one.
- The keyboard page no longer carries a permanent line of internal commentary about the
  Fn+Space listener. Only trouble is reported now, and in words.
- Lines that exist only when there is something to say no longer leave a gap behind when they
  have nothing.

## Fixed

- The chip names in the graphics drop-downs were built once at class load and kept whatever
  language was in force then.
- "BATTERY" did not fit a label width that had been measured for "AKKU".

## Verified

Full rebuild in Debug and Release without warnings. All smoke tests, the layout checks at 720,
1000 and 1600 pixels in both languages, and the worker process checks passed. The power scheme
path was tried end to end on this machine: duplicate, write, read back, activate, switch back,
delete — with the original plan confirmed untouched.

Not verified live: a real Windows restart with this version, and waking from suspend.
