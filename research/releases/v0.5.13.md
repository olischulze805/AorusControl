# AORUS Control 0.5.13

## The window fits the screen it opens on

The window always opened at its designed size of 1180 × 880 and was centred on the whole
screen. A 15.6" panel at 125 % scaling leaves only 816 points above the taskbar, so the title
bar - with minimise, maximise and close - ended up above the top edge, and the bottom of the
window behind the taskbar.

Every time the window is shown, from a normal start or from the notification area, it is now
limited to the usable screen area with a small gap and placed inside it. The designed size
stays the upper limit, so a large monitor still gets the full window, and a size or position
you chose yourself is kept as long as it still fits.

## Verified

Release build without warnings, the complete smoke-test suite and the offscreen UI checks at
all supported widths.
